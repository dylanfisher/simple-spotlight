# 0018. The app icon is an SVG, rendered when the bundle is built

- **Date:** 2026-11-01
- **Status:** accepted

## Context

Simple Spotlight had no icon, so Finder, the settings window and the app switcher showed the
generic one. Dylan picked the "Deeper Frost" sketch: a magnifier on a `#178bfb` tile, collaged
from a black scrap and a white scrap that each show it turned and slipped out of line. The
whites fade toward warm paper at the bottom and the blacks fade toward the top, as in Searcher's
icon, and the black lines fade to half. The bundle is put together by `scripts/bundle`, not
Xcode, so there is no asset catalog.

## Decision

`Sources/SimpleSpotlight/AppIcon.svg` is the only copy of the icon, as Searcher does it (its
decision 0104). `scripts/bundle` renders it with `sips` at the ten sizes an `.iconset` holds,
packs them with `iconutil` into `Contents/Resources/AppIcon.icns`, and `CFBundleIconFile` in
`Info.plist` names it. Both tools ship with macOS.

The SVG draws the tile at Apple's 824 px shape on a 1024 px canvas, so it lines up with other
apps' icons. The scraps are masks whose contents sit in a group with opacity: WebKit applies a
mask to each layer inside it separately, which leaves light seams where a scrap's edge crosses
the lens.

## Alternatives considered

- **Check in the `.icns`.** A binary that has to be regenerated by hand whenever the SVG changes,
  and nothing would notice when they diverged.
- **`rsvg-convert` or another renderer.** A new dependency; `sips` renders this SVG correctly on
  the build machine, including the masks.

## Consequences

Editing the icon means editing the SVG; the next `./scripts/bundle` or `./scripts/dev` picks it
up. `sips` on macOS 12 reads SVG but writes nothing and exits 0, so `scripts/bundle` checks each
file and fails there. The project builds on the build machine, so this only matters there. Quick Look renders the
SVG on macOS 12 (`qlmanage -t -s 512 -o <dir> AppIcon.svg`) for a look at it there. The design
sketches that led to it are not in the repo.
